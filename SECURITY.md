# Security policy

This repository is an unvalidated research prototype and is not supported for high-risk policy enforcement or consequential automation.

Report vulnerabilities privately through the repository Security tab. Do not put live credentials, personal data, or unpatched vulnerability details in a public issue. Include the affected commit, reproduction steps, impact, and a minimal safe proof of concept.

A security fix does not validate ethical, safety, or production-readiness claims. High-risk integrations must remain fail closed and require independent review.
